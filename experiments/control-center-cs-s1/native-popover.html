CS-S1 · Aiuto contestuale

Laboratorio isolato. Confronta il comportamento attuale del Control Center con un candidato basato sulle API native del browser. Non modifica il runtime pubblico.

A · Baseline personalizzata

Replica minima del comportamento attuale: contenitore con role="dialog", apertura gestita da JavaScript, chiusura con pulsante o Escape.

B · Candidato nativo

Usa popover="auto" e un invocatore dichiarativo. Il browser gestisce relazione con l’invocatore, ordine del focus e chiusura leggera.

Confine della prova
La variante Web Awesome resta un confronto di capacità/documentazione: nessuna dipendenza di runtime viene installata o autorizzata da questo laboratorio.
