# Registro di continuità visuale e audiovisiva
Modello operativo da associare a storyboard, inventario di consegna e registro di provenienza Visual Factory esistenti; non nuovo contratto di pubblicazione.

Archivio autorizzato / riferimento e prova di recupero:
Revisione umana, data e riferimento (non precompilare):

| ID stabile | Scena/stato e funzione | Tipo (ispirazione/bozza/master/derivato) | File canonico e SHA-256 | Origine, diritti, sorgente | Stato revisione | File effettivo nel prodotto e SHA-256 | Evidenza di integrazione |
|---|---|---|---|---|---|---|---|
| | | | | | NON REVISIONATO | | |

Per derivati: ID master, hash master, ricetta/trasformazione, hash derivato, verifica resa; una trasformazione che altera identità, messaggio o contenuto necessita revisione. Per immagini composte nello storyboard, conservare anche le singole scene/oggetti quando realmente disponibili; non fingere editabilità o estrazione senza perdita. Per asset approvati esclusi: motivazione, decisione umana e riferimento. Per ogni scena/stato previsto verificare il file o derivato effettivamente caricato/visualizzato; per HTML incorporato, estrarre i byte e confrontare l'impronta, quindi verificare la resa. Per PDF/video verificare anche composizione e riproduzione effettive. Non confondere presenza con uso reale.

Per avventure: il master può essere una scena artistica completa. Separare oggetti o personaggi solo per esigenze reali di interazione o regia. Registrare tipo di richiesta (SCENA ARTISTICA / DETTAGLIO O VARIANTE NARRATIVA / STUDIO INTERFACCIA); uno studio di interfaccia non è un master artistico. Collegare ogni elemento esplorabile al master, alla zona relativa all'immagine, alla conseguenza prevista, all'eventuale risorsa derivata e all'alternativa accessibile; conservare il mapping nel dossier di regia, non come nuovo manifesto. Nessuna dichiarazione di livelli editabili non disponibili.

Checklist:
- Originali salvati e recuperati con verifica hash.
- Tutte le risorse approvate collegate a scene e stati.
- Derivati tracciati, master non sovrascritti.
- File integrati verificati sul candidato esatto.
- Nessuna risorsa approvata sostituita o esclusa senza decisione.
- Lacune, diritti, conservazione remota e revisione dichiarati separatamente.
Stato predefinito: NON VERIFICATO. Un inventario strutturale non dimostra conservazione durevole, revisione umana o effettiva resa. Nessuna pubblicazione implicita.
