# Consegna editoriale
Identità e versione proposta, brief, fascicolo didattico obbligatorio (templates/teacher-dossier.md: scheda sintetica, guida, materiali operativi, matrice e strumenti facoltativi), rapporto di qualificazione della versione con stato distinto della sperimentazione, prodotto fruibile, sorgenti quando disponibili, media, testo/sottotitoli, report verifiche. Per ogni file indicare percorso relativo, SHA-256, bytes, origine e stato diritti. Generare un inventario locale con:
python scripts/preflight.py <cartella-prodotto> --output <rapporto-esterno.json>
Il rapporto va salvato fuori dalla cartella inventariata. Non includere credenziali, file personali, archivi non ispezionati o collegamenti temporanei come asset. Il rapporto inventaria i file e non li esegue. Non è un validatore di diritti, privacy semantica o ActivityPackage. Acquisizione richiede canale effettivo, controllo canonico e consenso; pubblicazione separata.
