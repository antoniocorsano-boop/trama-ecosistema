# P0/P1 Penpot MCP read-only probe

This harness verifies that a protected Penpot MCP endpoint can be reached from GitHub Actions and that MCP tool discovery succeeds.

It performs only:

- MCP connection / negotiation;
- `tools/list`.

It does **not** call any Penpot write tool.

## Secret

Configure the repository Actions secret:

`PENPOT_MCP_URL`

with the full Penpot MCP remote endpoint generated by Penpot.

Because that URL can contain `userToken`, it must never be committed, added to PR text, comments, logs or screenshots.

## Execution

Run the workflow:

`Penpot MCP P0-P1 read-only probe`

manually with `workflow_dispatch`.

PASS requires:

- MCP transport connection succeeds;
- protocol negotiation succeeds;
- `tools/list` returns one or more tools;
- no tool call that mutates Penpot is executed.

This is a connectivity/read-only capability check, not a human visual review.
