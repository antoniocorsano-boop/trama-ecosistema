# Base di conoscenza federata

## Decisione

TRAMA adotta una base di conoscenza federata. Non esiste una copia completa comune di curricolo, materiali e contesto professionale.

| Dominio | Contenuto autorevole |
| --- | --- |
| TRAMA | decisioni, contratti, architettura e stato comune |
| Arena | curricolo, fonti, applicabilità e approvazioni |
| Atlas | relazioni, percorsi e oggetti di apprendimento |
| Docente OS | contesto professionale, preparazione e diario |
| Drive | documenti collaborativi, rapporti e copie di consultazione |

## Indice federato

Il file [source-registry.json](source-registry.json) collega ogni dominio alla fonte autorevole e dichiara il comportamento delle copie.

## Requisiti delle copie

Una copia leggibile deve riportare:

- fonte autorevole;
- versione o riferimento;
- data di aggiornamento;
- stato;
- indicazione che la copia non sostituisce l'originale.

## Prevenzione delle divergenze

- non copiare registri macchina in Drive;
- non copiare il curricolo completo in TRAMA;
- non usare Atlas come fonte curricolare di Docente OS;
- non usare documenti collaborativi come stato runtime;
- aggiornare i riferimenti mediante richieste tracciate.
