# CAP-ATLAS-PERCORSI — Backlog-Zero Consolidation Plan v1

**Gate:** G1 — Discovery / industrialisation
**Status:** ACTIVE CONSOLIDATION PLAN
**Runtime:** NOT_AUTHORIZED

## Objective

Keep Atlas Percorsi continuously organised while the evidence review expands. Research, reasoning, experiments and design decisions must be classified as they are produced so that the project does not accumulate a documentation backlog that later has to be reconstructed from conversations.

## Backlog-zero rule

Every meaningful artefact produced during G1 must end the work cycle in one of five states:

- **CANONICAL** — current governed reference;
- **SUPPORTING** — valid evidence/reasoning linked from a canonical artefact;
- **EXPERIMENTAL** — retained with explicit question, result and limitations;
- **SUPERSEDED** — historically useful but replaced by a named canonical artefact;
- **ARCHIVE_CANDIDATE** — no current design authority; retained only for traceability until archival action is governed.

No meaningful file should remain in an implicit or ambiguous state.

## Current consolidation workstreams

### C1 — Scientific evidence review

Convert broad research into screened evidence packets. Priority domains:

1. competence acquisition and transfer;
2. metacognition/self-regulation without profiling;
3. cognitive load, multimedia learning, attention and memory;
4. narrative comprehension and visual narrative;
5. comics/manga and sequential meaning;
6. animation/anime, pacing and temporal control;
7. character viewpoint and perspective-taking;
8. interactive/branching narrative;
9. inquiry/evidence reasoning;
10. simulation/microworlds;
11. constructionism/making;
12. accessibility, low-stimulation design and neurodiversity;
13. child-safe persuasive/gamified design;
14. Italian/EU normative and competence frameworks.

Each packet ends with implications classified as **SUPPORTED / UNCERTAIN / UNSUPPORTED / CONTRAINDICATED**.

### C2 — Existing artefact census

Inventory all existing Atlas Percorsi documents and classify them. Particular attention is required for older files at the capability root that predate the newer architecture/research/templates/prototypes organisation.

Do not bulk-move or delete during census. First identify authority and inbound references.

### C3 — Decision reconciliation

Reconcile earlier metaphor work with the newer pathway-specific narrative architecture.

Known direction to preserve:

- contextual continuity remains a cross-pathway hypothesis;
- Journey/Crossroads is no longer a universal target metaphor;
- local devices are selected by cognitive function;
- narrative identity is pathway-specific;
- evidence precedes promotion of a grammar;
- attractive generated visuals cannot silently become specification.

Older documents that imply a universal metaphor must be marked SUPERSEDED or reframed as historical experiments rather than silently left authoritative.

### C4 — Productive repository structure

Progressively establish:

- constitution/safeguards;
- reusable research library;
- experiential-grammar registry;
- templates/schemas;
- concrete pathway dossiers;
- workflow/gates/checks;
- experimental prototypes separated from canonical specifications.

Physical reorganisation follows reference analysis; information architecture comes first.

### C5 — Competence progression model

Do not reduce Percorsi to engaging content consumption. Define and evidence a progression architecture capable of supporting repeated practice and transfer:

`SITUATED ACTION → FEEDBACK/CONSEQUENCE → STRATEGY RECOGNITION → VARIATION → RETRIEVAL → TRANSFER → INCREASING AUTONOMY`

This is a research/design hypothesis until supported by the evidence review.

Avoid claims that play automatically produces high competence. Percorsi should create opportunities to practise and demonstrate increasingly sophisticated competence; the actual effects require validation.

## Definition of done for each research/design cycle

Before closing a work cycle:

- evidence found is registered or explicitly rejected;
- important reasoning is preserved;
- affected canonical documents are identified;
- experimental artefacts have an outcome/limitation note;
- superseded decisions name their replacement;
- unresolved questions enter a visible research/gate list;
- no decision exists only in chat history;
- no new runtime authority is inferred from research progress.

## Immediate sequence

1. Complete the capability artefact census.
2. Create a canonical index/status map for every existing document.
3. Screen the first scientific evidence packets, starting with learning/transfer and cognitive/multimedia foundations before medium-specific aesthetics.
4. Seed the experiential-grammar registry only with evidence status `research`.
5. Reclassify the existing shared-decision work as a concrete decision/collaboration experiment.
6. Create a second pathway with a different cognitive structure only after the common evidence base is sufficiently stable.
7. Introduce deterministic repository checks once the dossier/registry schemas stabilise.

## Success criterion

At any point, a new contributor should be able to enter the repository and determine without chat history:

- what Atlas Percorsi is trying to achieve;
- which claims are evidence-supported and which remain hypotheses;
- which documents are canonical;
- which experiments were run and what they taught;
- which safeguards are mandatory;
- how a new pathway is created;
- what remains unresolved;
- what is and is not authorised for implementation.
