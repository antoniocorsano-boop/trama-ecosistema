## Experiment performed

A first visual comparison was generated as a 3×3 board crossing:

- literal presentation;
- Journey/Crossroads;
- Workshop/Tools;

with:

- early primary;
- later primary;
- lower secondary.

The generated image is an exploratory visual artefact, not a product mock-up and not approved Atlas visual language.

## Important methodological limitation

The generated board does **not** preserve the controlled scenario exactly enough: it shifts the original shared-decision scene toward a school-park improvement scenario and introduces richer illustration than a true low-fidelity prototype should contain.

This deviation is useful evidence in itself. Generative visual production can silently alter pedagogical variables while appearing coherent. Therefore future comparison assets must be produced from stricter frame-by-frame specifications, and textual/structural equivalence must be checked before visual attractiveness is considered.

## What the experiment makes visible

### Literal

Strengths observed:

- educational action is immediately legible;
- consequences and trade-offs can be represented explicitly;
- easiest baseline for accessibility and age adaptation.

Risks observed:

- can become worksheet-like;
- information density rises quickly in later age bands;
- atmosphere/coherence may be weak if it is treated merely as cards and text.

### Journey/Crossroads

Strengths observed:

- choices and consequences become spatially legible;
- revisability can be represented naturally by returning to a junction;
- strong orientation potential.

Risks observed:

- landscape/character imagery can capture attention more strongly than the reasoning target;
- signs/path geometry can accidentally encode preferred answers;
- illustration novelty can turn every decision into a new scene;
- lower-secondary rendering requires a much more restrained, map-like language to avoid infantilisation.

### Workshop/Tools

Strengths observed:

- strategy-as-tool is immediately concrete;
- supports the idea that strategies are selected for situations rather than possessed as traits;
- potentially strong bridge toward metacognition and transfer.

Risks observed:

- tools can become collectible/game-like objects;
- physical tool imagery can over-materialise social and cognitive processes;
- a workshop aesthetic can dominate the human situation;
- lower-secondary version can drift into a generic productivity dashboard.

## Child-attention observation

The experiment confirms a design concern already preserved in research reasoning: attractive imagery can become the dominant memory target. In the Journey panels especially, scenery and character illustration compete with the pedagogical relation. This is not proof about children's behaviour, but it is a sufficient design warning to reduce visual novelty before any child-facing evaluation.

## Correction for the next visual iteration

The next visual comparison must:

1. return to the **same exact fictional shared-decision scenario** across all variants;
2. compare one age band at a time rather than nine rich panels simultaneously;
3. use grayscale/wireframe or extremely restrained colour first;
4. keep identical text, number of choices, character positions and consequence content where possible;
5. vary only the metaphorical scaffold;
6. avoid decorative landscape, expressive emotional faces and collectible-looking objects;
7. include the literal instruction in every variant;
8. show the low-stimulation equivalent beside the metaphorical version;
9. include a transfer frame that changes context without repeating answer cues;
10. record every deliberate visual difference and its pedagogical rationale.

## Generated-asset governance rule

For Atlas Percorsi, AI-generated visual material cannot be treated as a faithful implementation of a storyboard merely because the prompt contains the storyboard concepts.

Before an AI-generated visual enters the governed design record, it must be checked for:

- scenario fidelity;
- age-band fidelity;
- unintended emotional coding;
- unintended moral/correct-answer coding;
- privacy/safety violations;
- accessibility assumptions;
- extra characters/text/actions not specified;
- visual salience that changes the cognitive task;
- stereotypes or identity implications;
- text accuracy and language quality.

A visually successful but pedagogically divergent generation is **evidence for iteration**, not an approved design.

## Decision

**Do not select a metaphor from this image.**

The experiment supports continuing with all three conditions as controlled candidates, but it also demonstrates that polished illustration is premature. The next valid visual prototype should focus on **one age band, one exact scene, three structurally equivalent low-fidelity variants**.

Recommended next comparison: **later primary**, because it permits enough reasoning complexity to expose metaphor effects while remaining concrete enough to reveal visual/cognitive overload early.
