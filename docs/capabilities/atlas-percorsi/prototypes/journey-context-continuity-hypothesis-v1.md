# CAP-ATLAS-PERCORSI — Journey / Context Continuity Hypothesis v1

**Gate:** G1 — Discovery  
**Status:** LEADING_HYPOTHESIS / NOT_SELECTED  
**Origin:** controlled metaphor comparison + human review  
**Runtime:** NOT_AUTHORIZED

## Observation to preserve

Human review identified a material advantage in the **Journey/Crossroads** condition: it provides not only a metaphor for choosing, but a **coherent context** in which place, situation, decision and consequence can remain connected over time.

This is stronger than visual attractiveness. It suggests a possible narrative architecture for Atlas Percorsi.

## Hypothesis

A journey-based scaffold may support competence development when it creates **contextual continuity**:

`ENTER CONTEXT → ORIENT → NOTICE → ENCOUNTER A DECISION → CHOOSE → OBSERVE CONSEQUENCE → RECONSIDER → CARRY INSIGHT FORWARD → MEET A CHANGED CONTEXT`

The educational value would therefore come from continuity and consequence, not from adventure aesthetics.

## What must remain invariant

- literal task comprehension without decoding the metaphor;
- no correct-answer coding through road colour, brightness, length or attractiveness;
- no fantasy reward loop;
- no forced linear progression when reconsideration is pedagogically useful;
- no identity score or public progress ranking;
- no personal disclosure requirement;
- no account/profile/tracking requirement;
- low-stimulation and reduced-motion equivalence;
- age-respectful visual language.

## Context continuity contract

If Journey/Crossroads remains the leading candidate, a sequence must preserve enough stable context that the learner can answer:

1. Where am I in the experience?
2. What situation am I dealing with?
3. What changed because of the previous action?
4. What have I learned that can help now?
5. What is genuinely new in this next context?

A scene change that cannot answer these questions risks becoming decorative novelty.

## Relationship with Workshop/Tools

The Workshop/Tools concept should not be discarded. Its strongest idea is **strategy-as-tool**: a strategy is selected according to a situation rather than treated as a personal trait.

A candidate synthesis to test is therefore:

- **Journey = contextual/narrative architecture**;
- **Tools = reusable strategy representation inside the journey**.

This is **not** permission to create collectible items, inventories, unlock mechanics, rarity levels, badges or reward economies.

A strategy becomes available because the learner has encountered, understood and used it—not because an engagement mechanic awards an object.

## Candidate multi-scene arc

### Scene A — Entry
A coherent ordinary/fictional context establishes a shared problem. No spectacular opening is required.

### Scene B — First crossroads
The learner encounters a bounded decision. The context remains visually stable.

### Scene C — Consequence
The same world shows what changed. The learner is not moved to a wholly new illustration merely for novelty.

### Scene D — Reflection / strategy recognition
The learner identifies a reusable strategy. A restrained tool/lens/card representation may name the strategy without turning it into a reward.

### Scene E — Changed context
The journey continues into a different but related situation. Stable anchors preserve orientation; the learner must decide whether the earlier strategy fits.

### Scene F — Transfer
The surface context changes enough that success cannot come from repeating the same icon/path cue.

### Scene G — Learner-controlled trace
A compact local artefact may preserve the strategy insight without creating a student profile.

## Age-band evolution

### Early primary
Journey is concrete and spatial, with very few landmarks and one dominant focus. The context should resemble an understandable place/situation rather than a fantasy universe.

### Later primary
Journey can represent alternatives, consequences and return/revision. Context may become richer but must remain stable enough to avoid visual replacement churn.

### Lower secondary
Journey should become more restrained and diagrammatic: route, orientation, decision landscape, trade-offs. Avoid quest aesthetics, mascots and infantilising adventure language.

The narrative architecture may remain constant while its visual expression matures.

## Emotional-development safeguard

The context can make social/emotional situations meaningful without requiring autobiography. Fictional distance remains available.

The journey must never imply that:

- a difficult emotion is an obstacle to defeat;
- a learner has a fixed emotional type;
- one path represents a morally superior person;
- progress means becoming permanently calm, confident, sociable or compliant.

The learner encounters situations and strategies, not a diagnostic journey through the self.

## Visual-memory safeguard

Context continuity should reduce, not intensify, the image-replacement problem already identified in G1.

Prefer:

- stable background/landmarks;
- selective change;
- repeated meaningful symbols;
- explicit retrieval of earlier insight;
- learner-controlled transitions;
- visual novelty only when new pedagogical information requires it.

Avoid:

- a completely new illustration for every choice;
- cinematic transitions whose memory competes with the concept;
- character reactions designed primarily to amplify emotion;
- scenery whose detail exceeds its pedagogical role.

## Validation questions

Before selecting Journey as the canonical metaphor, test whether:

- contextual continuity improves orientation compared with the literal baseline;
- learners remember the decision/consequence relation, not only the setting;
- earlier strategies can be retrieved in a changed context;
- the path metaphor does not imply a single predetermined correct life route;
- revising a decision feels legitimate;
- older students do not perceive the framing as childish;
- the literal/low-stimulation version preserves equivalent meaning;
- the same architecture can support different transversal competence territories without forcing every experience into a journey cliché.

## Current decision state

**Journey/Crossroads becomes the leading candidate for the next prototype because of its contextual continuity, not because it is visually more attractive.**

**Workshop/Tools remains a candidate subordinate mechanism for representing reusable strategies.**

No canonical metaphor is selected at G1 yet. The next experiment must test a short **multi-scene Journey sequence** against the literal baseline while preserving the same pedagogical content and measuring conceptual continuity, orientation and transfer rather than preference alone.
