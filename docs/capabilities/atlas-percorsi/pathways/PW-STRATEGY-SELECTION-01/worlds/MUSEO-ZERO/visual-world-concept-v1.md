# MUSEO ZERO — Visual World Concept v1

**Status:** ART_DIRECTION_CANDIDATE / HUMAN_PRODUCT_REVIEW_REQUIRED  
**Runtime:** NOT_RUNTIME_AUTHORIZED

## 1. Visual promise

**A contemporary museum after closing time, half exhibition and half backstage machine.**

The learner should feel they have access to a place visitors normally do not see.

## 2. Art direction

Preferred:
- polished 2-D illustrated environment;
- semi-isometric / cutaway spatial view;
- contemporary editorial-game aesthetic;
- warm evening museum light;
- bold exhibition colour accents;
- controlled depth/shadows;
- characters stylised but not childish;
- equipment simplified into readable shapes.

Avoid:
- school worksheet styling;
- generic SaaS cards;
- chibi/mascot treatment;
- photorealism;
- sterile engineering schematic as primary world;
- neon sci-fi interface.

## 3. Persistent spatial anchor

Primary world view:
- a compact cutaway/map of four museum zones.

The learner can see:
- where they are;
- which places changed state;
- where evidence has been inspected;
- current room readiness.

Location transitions should feel like zooming into the same world, not loading a new page.

## 4. Sala Zero visual identity

Core elements:
- one large projection wall;
- floor light path;
- entry sensor embedded in floor;
- ceiling/speaker cue;
- exit light;
- new visitor route marking.

The room’s state should be readable at a glance:
- idle;
- failed sync;
- test mode;
- synchronised.

## 5. Cabina regia

Should feel tactile and comprehensible:
- cue chain represented as connected blocks;
- trigger label visible;
- timeline trace;
- large TEST action.

Avoid dense professional AV-console realism.

## 6. Characters

Lia, Omar, Teo:
- stable silhouettes and clothes;
- appear physically in relevant locations;
- expressions/reactions tied to world state;
- no floating avatar heads as default dialogue pattern.

Dialogue may appear as:
- short speech bubble anchored to character;
- optional expandable detail.

## 7. Information objects

Evidence should look like world objects:
- tape label on sensor case;
- rehearsal note on clipboard;
- route sketch taped to wall;
- cue mapping on control display;
- recorded room preview.

Avoid turning each into a white rounded card unless needed for accessibility/detail expansion.

## 8. Interaction feel

Prefer:
- tap location to zoom;
- tap object to inspect;
- drag/pin evidence onto work surface where meaningful;
- connect nodes on dependency surface;
- run test and watch room;
- toggle comparison criteria.

Motion:
- short, causal and state-revealing;
- no decorative bounce/confetti.

## 9. Mobile composition

The world remains primary.

Target:
- world/state occupies top/central dominant area;
- controls appear contextually;
- work surface can temporarily replace/overlay lower area without losing world reference;
- instructions are diegetic/compact.

Do not stack:
header → explanation card → map card → character card → tool card → task card.

## 10. Visual quality gate

Before code implementation, a visual concept must demonstrate at least:

1. museum cutaway/world;
2. Sala Zero failed state;
3. Cabina regia trigger mismatch;
4. one character-in-world interaction;
5. synchronised successful rehearsal state.

If these cannot carry the experience visually, return to art direction before UI engineering.
