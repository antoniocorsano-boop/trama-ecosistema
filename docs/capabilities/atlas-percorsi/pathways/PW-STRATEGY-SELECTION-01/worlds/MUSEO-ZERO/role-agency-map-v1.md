# MUSEO ZERO — Role / Agency Map v1

**Status:** DESIGN_CANDIDATE / HUMAN_PRODUCT_REVIEW_REQUIRED  
**Runtime:** NOT_RUNTIME_AUTHORIZED

## 1. Learner role

**Junior setup operator**

Functional responsibility:

> Build enough understanding of the room to help the crew decide what to test and what to change.

The learner is neither a passive assistant nor the sole expert.

## 2. Agency layers

### A1 — Navigation agency

Learner chooses which location to inspect:
- Ingresso
- Sala Zero
- Cabina regia
- Laboratorio

No required canonical visit order.

### A2 — Evidence agency

Learner decides which traces are relevant:
- route sketch;
- sensor label;
- cue mapping;
- rehearsal timestamp;
- character statement;
- room recording.

Evidence can be pinned/unpinned.

### A3 — Representation agency

Learner may organise evidence using available tools:
- timeline;
- connection/causal view;
- comparison view.

The system does not announce “now use strategy X”.

### A4 — Testing agency

Learner can run safe simulations:
- old trigger mapping;
- new trigger mapping;
- manual cue;
- route variants where appropriate.

Simulation changes room preview.

### A5 — Decision agency

Learner recommends a recovery plan.

Recommendation must cite visible evidence/constraints.

## 3. Non-agency / boundaries

Learner cannot:
- bypass accessibility constraints;
- make unsafe electrical changes;
- remove evidence that contradicts the model;
- access hidden personal information;
- win through arbitrary guessing without observing consequences.

## 4. Character agency relationship

### Lia
Can:
- clarify route/spatial changes;
- react if recommendation conflicts with visitor flow/access.

### Omar
Can:
- clarify sensor/installation state;
- react to hardware assumptions.

### Teo
Can:
- provide rehearsal/test evidence;
- run the crew’s next rehearsal after recommendation.

Characters may challenge an unsupported model.

They do not:
- reveal the answer after one error;
- praise identity/intelligence;
- use intimacy/relational pressure.

## 5. Agency-to-competence map

| Learner action | Why it matters |
|---|---|
| chooses locations/evidence | learner must determine what information is useful |
| builds timeline | chronology becomes usable |
| notices timeline cannot establish cause | monitors representation adequacy |
| builds/uses dependency map | changes method when question changes |
| runs simulation | tests whether model explains behaviour |
| compares fixes | changes representation again for decision task |
| revises after consequence | strategy use becomes evidence-based rather than label-based |

## 6. Meaningful-choice test

A choice is meaningful only if at least one changes:
- information revealed;
- current model;
- simulated state;
- available interpretation;
- crew decision;
- final room state.

Cosmetic choices do not count as agency.

## 7. Mobile constraint

Agency must not depend on tiny free-roaming movement.

Navigation can use:
- persistent illustrated map;
- location zoom;
- inspectable objects;
- stateful hotspots.

The learner should feel free to investigate without needing joystick/game controls.
