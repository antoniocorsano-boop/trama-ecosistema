# MUSEO ZERO — Experience Choreography v1

**Status:** DESIGN_CANDIDATE / HUMAN_PRODUCT_REVIEW_REQUIRED  
**Runtime:** NOT_RUNTIME_AUTHORIZED

## 1. Opening: begin with failure

No premise card.

The learner enters during a failed rehearsal.

Visible:
- visitor crosses the new entry;
- nothing triggers;
- projection starts late;
- sound arrives after the visual moment;
- crew notices the mismatch.

Short diegetic reactions:
- Teo: “Aspetta. Di nuovo in ritardo.”
- Lia: “Ieri qui funzionava.”
- Omar: “Il sensore si accende. Quindi che cosa non torna?”

Curiosity exists before instruction.

## 2. Invitation

Crew acknowledges learner role:

> “Ci dai un’occhiata? Ognuno di noi ha cambiato qualcosa oggi.”

The museum map becomes inspectable.

No required first location.

## 3. Free inspection loop

Learner may visit:
- Ingresso
- Sala Zero
- Cabina regia
- Laboratorio

At each place:
- environment reveals visual state;
- one or two inspectable objects;
- optional character exchange;
- evidence can be pinned.

Loop:
`INSPECT → NOTICE → PIN/IGNORE → MOVE`

## 4. First representation emerges

When enough temporal traces are visible, learner can open the work surface.

Available tools are represented functionally, not educationally:
- “Metti in fila i cambiamenti”
- “Collega ciò che dipende da cosa”
- “Confronta le soluzioni”

The learner may choose.

For the question “what changed before failure?”, timeline proves most useful.

## 5. World response to chronology

A correct enough timeline produces no “Correct!” screen.

Instead:
- crew replays the sequence against the room;
- everyone sees the route/sensor move happened before the failed rehearsal.

Teo:
> “Ok. Ora sappiamo quando è cambiato. Ma non ancora perché parte tardi.”

The world generates the next question.

## 6. Causal investigation

Learner returns to world with new purpose.

Now:
- physical sensor location matters;
- cue mapping matters;
- test function matters.

Learner may build connection model or directly inspect/test.

The key moment is **representation inadequacy**:
timeline contains the events but cannot show dependency.

## 7. Safe simulation

Learner can change only simulated trigger mapping.

Run current:
- failure repeats.

Run Sensor B:
- room synchronises.

World visibly responds.

This is the experiential centre of the pathway.

## 8. Decision phase

Maya/crew introduces practical question:

> “Per la prossima prova cosa facciamo?”

Learner sees three recovery options and constraints distributed in world.

A comparison representation becomes useful.

## 9. Recommendation

Learner recommends and runs one final simulated rehearsal.

### Supported recommendation
Room state:
READY FOR REHEARSAL.

### Weak recommendation
Room reveals limitation and invites revision.

No dead end.

## 10. Quiet close

The room runs.

Characters react briefly:
- Teo: “Adesso parte quando entra il visitatore.”
- Omar: “Quindi il sensore era a posto. Era il collegamento.”
- Lia: “Perfetto. Il nuovo percorso può restare.”

Then the world settles into ready state.

No “lesson learned” panel.

## 11. Rhythm target

`FAILURE → EXPLORE → ORGANISE → NEW QUESTION → TEST → SEE CONSEQUENCE → COMPARE → DECIDE → WORLD WORKS`

Avoid:
`INSTRUCTION → TASK → CHECK → NEXT`

## 12. Approximate duration target

Prototype target:
- 8–12 minutes for first completion;
- no requirement to inspect every optional detail;
- meaningful path can vary.

Duration is a design target, not a hard gate.
