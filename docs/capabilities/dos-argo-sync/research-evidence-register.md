## Evidence quality rules

- distinguish source fact from interpretation;
- retain exact source/version/page when available;
- record uncertainty explicitly;
- do not infer undocumented Argo behavior;
- do not treat a generated spreadsheet as compatible until validated by import evidence;
- do not promote a G1 hypothesis to a G2 decision without governed review.

## E-001 — Argo didUP manual

**Source:** *Il registro elettronico Argo — Manuale del docente e del coordinatore, didUP 4.54.0*  
**Updated:** 07/09/2026  
**Relevant pages:** 99–101, especially 100–101  
**Source provenance:** user-supplied project evidence reviewed on 30/09/2026  
**Evidence status:** DIRECT / CURRENT_FOR_DISCOVERY

### Supported facts

1. The Programma Scolastico supports modules and arguments.
2. A program can be imported from another class.
3. The source class/program can come from a previous school year.
4. didUP exposes an XLS import/export function for Programma Scolastico.
5. The manual strongly advises against modifying the original XLS generated by didUP to avoid import blocking.

### What E-001 does not establish

The manual excerpt does **not** establish:

- a public/stable XLS schema;
- that arbitrary XLSX or CSV files can be imported;
- that an independently reconstructed XLS will be accepted;
- update/merge semantics for records already present;
- duplicate-detection rules;
- selective deletion semantics;
- a supported API for writing Programma Scolastico;
- browser automation compatibility.

These remain open discovery items.
