# Modello di maturità

| Livello | Descrizione |
| --- | --- |
| M0 | concetto non formalizzato |
| M1 | responsabilità e perimetro documentati |
| M2 | contratti e dati dimostrativi verificabili |
| M3 | flusso funzionante in ambiente controllato |
| M4 | pilota reale con verifiche automatiche e umane |
| M5 | adozione istituzionale governata e assistita |

Il livello deve essere assegnato a una capacità specifica e a una revisione identificabile, non al nome generico del prodotto.

## Dimensioni trasversali

- correttezza funzionale;
- accessibilità e usabilità;
- provenienza;
- sicurezza e privacy;
- controllo umano;
- reversibilità;
- operabilità e assistenza;
- sostenibilità organizzativa.
