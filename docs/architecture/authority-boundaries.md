# Confini di autorità

| Informazione o decisione | Autorità | Consumatori ammessi |
| --- | --- | --- |
| curricolo e applicabilità | Arena | Atlas e Docente OS |
| stato approvativo | Arena e processo umano | Atlas e Docente OS |
| identità e stato di una risorsa | Atlas | Docente OS |
| scelta di usare una risorsa | docente | Docente OS |
| classe, data e orario | Docente OS | interno al dominio docente |
| diario e adattamenti | docente | Docente OS |
| contratto trasversale | TRAMA | tutti i prodotti interessati |
| adozione istituzionale | organi competenti | sistemi autorizzati |

## Regole

1. Un consumatore non può promuovere una copia a fonte autorevole.
2. Un identificativo di versione non sostituisce il controllo dell'impronta significativa.
3. Lo stato di una risorsa non determina la sua adozione nella lezione.
4. Una dimostrazione non equivale a capacità operativa.
5. Una decisione approvata non equivale a implementazione completata.
