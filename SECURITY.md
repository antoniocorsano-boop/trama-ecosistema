# Sicurezza e protezione dei dati

## Segnalazioni

Le vulnerabilità non devono essere pubblicate in una discussione aperta. Utilizzare il canale privato di segnalazione della sicurezza del repository quando disponibile.

## Dati esclusi

Il repository non deve contenere dati personali, dati di classe, elaborati degli studenti, credenziali, token, chiavi o configurazioni riservate.

## Principi

- minimizzazione dei dati;
- separazione dei domini;
- autorizzazione esplicita;
- provenienza verificabile;
- registrazione degli esiti senza dati personali;
- nessuna automazione autonoma delle decisioni professionali.
